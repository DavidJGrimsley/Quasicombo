# Quasicombo

This repository contains the Unreal Engine project code and configuration. The `Content` directory is intentionally omitted because the game uses licensed art and audio assets that are not redistributed as editable project files.

A playable **Win64 Shipping build, built October 10, 2026**, is available in [release-2026-10-10](https://github.com/DavidJGrimsley/Quasicombo/releases/tag/release-2026-10-10). Download both numbered ZIP parts, `README.txt`, and `Reassemble.ps1` from the release. Follow the joining instructions, extract the entire ZIP, and launch `Braided_Quanta2026.exe`. The complete runtime and Visual C++ prerequisite installer are included. The [September build](https://github.com/DavidJGrimsley/Quasicombo/releases/tag/playtest-2026-09-27) remains available.

This update includes the merged menu and current level design, How to Play, pause Restart/Quit, a seven-second combo timer that holds during evolution cinematics and QTEs, boss enemy cleanup, rounds display, and the PCG floating background. It exports the validated private Diversion source commit `dv.commit.116`, merged into private `main` as `dv.commit.117`. Source, configuration, Quantum API plugin source, Project scripts/docs, documentation, and the project descriptor are included. Configured credentials and licensed editable Content/audio/animation assets are excluded; rebuilding requires the missing licensed assets and Unreal Engine 5.8. Configure your own Quantum credentials for live API use.

Complete Development and Shipping cooks/packages passed with **zero errors and four imported-content warnings each**. Validation included 44 unique native regressions, focused PIE checks, live Quantum responses, and a fresh extracted Shipping smoke test covering menu navigation, movement/jump, scenery, pause/Resume, Restart/Quit, and settings persistence. World Partition streaming remains disabled, so cell unloading/reloading was not exercised. See [GameBuildIssues.md](GameBuildIssues.md) for detailed validation and remaining limits, and the release's manifests/checksums for build provenance.
