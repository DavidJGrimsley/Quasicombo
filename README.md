# Quasicombo

This repository contains the Unreal Engine project code and configuration. The `Content` directory is intentionally omitted because the game uses licensed art and audio assets that are not redistributed as editable project files.

A playable Windows build is provided in [Releases](https://github.com/DavidJGrimsley/Quasicombo/releases). Download both numbered ZIP parts from the latest release and follow its instructions to join and extract them.

The source snapshot is from the private project's GitHub `main` commit `8e01f173ff608278b248f34ca19070eb9ea2b84a`. The Windows build was packaged separately on September 27, 2026. Rebuilding from this source requires the missing content assets and Unreal Engine 5.8.
